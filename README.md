# Rawla Jojawar — A Heritage Hotel Website

A modern, luxury heritage hotel website for **Rawla Jojawar – A Heritage Hotel** (Pali, Rajasthan, India), built with **React**, **Tailwind CSS**, and **Vite**.

---

## 🌟 Key Features & Architecture

- **Royal Rajasthan Visual Identity**: Deep Maroon (`#572323`), Dusty Rose (`#A87575`), Antique Gold (`#D4AF37`), Ivory/Cream (`#FDFBF7`), and custom Rajasthani Jali ornaments & arch dividers.
- **Cinematic Hero Carousel**: High-resolution curated palace photography, smooth transitions, Ken Burns zoom, custom typography, and Quick Booking Bar.
- **Heritage Story & Archives**: Detailed historical chronicles of the Rao of Jojawar, architectural preservation, and photo gallery modal.
- **Luxury Rooms & Suites**:
  - Deluxe Room
  - Superior Room
  - Royal Heritage Room
  - The Royal Suite / Maharaja Suite
  - Complete specifications (size, bedding, occupancy, view, 10+ amenities) with currency toggle (₹ INR / \$ USD) and "Know More" & "Book Now" modals.
- **Curated Activities & Safaris**: Town Walk, Vintage Jeep Safari, Heritage Meter-Gauge Train Safari, Marwari Horse Riding, Rabari Village Immersion, Bird Watching, Royal Courtyard Folk Dinners, and Culinary Masterclasses.
- **Why Choose Us & Animated Counters**: Viewport-triggered animated statistics (100% Satisfaction, 25 Rooms, 80+ Weddings, 500+ Safaris) and 6 royal pillars.
- **Filterable Gallery & Fullscreen Lightbox**: Filter by Hotel, Rooms, Dining, Activities, and Weddings with interactive zoom and navigation.
- **Verified Guest Reviews Carousel**: 5-star ratings, testimonials, verified guest badges, and interactive "Write a Review" submission.
- **Destination Weddings & Events**: Full-width atmospheric section with celebration features and Event Planning RFP modal.
- **Discover Jojawar & Location**: Interactive map embed, distance table from Jodhpur Airport, Udaipur Airport, Ranakpur Temples, Kumbhalgarh Fort, and "Get Directions" link.
- **Interactive Booking Engine**: Real-time date calculator, room selector, meal plans (EP, CP, MAP), live tariff estimation (with GST), and instant voucher confirmation with one-click direct WhatsApp booking.
- **Deep Maroon Booking Banner & Royal Footer**: Direct phone numbers (+91 91191 69956, +91 94141 59969), email (jojawar@yahoo.com), social media links, newsletter, and trust seals.
- **Floating WhatsApp Concierge**: Fixed bottom-right circular button with subtle pulse animation and pre-filled message generator.
- **Mobile First & Responsive**: Smooth mobile hamburger drawer, touch-friendly controls, and seamless multi-column grid adaptations.

## 🚀 How to Run

### Development Mode
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
The optimized production build is ready in the `dist/` directory and can be deployed to any static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages) or served with any web server.
